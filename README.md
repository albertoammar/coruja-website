# Coruja Website

Landing page moderna da Coruja Sistemas — tecnologia para imobiliárias.

## Conteúdo

- `index.html` — site estático completo (HTML, CSS e JS inline)

## Visualizar localmente

```bash
npx http-server -p 8080 -c-1
```

Acesse: http://localhost:8080

## Stack

- HTML5, CSS3, JavaScript vanilla
- Google Fonts (Inter)
- Imagens via Unsplash e logos via Clearbit
